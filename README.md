# Aplikasi Perhitungan Ongkos Kirim Paket Berbasis Console TypeScript

# Deskripsi Aplikasi
Aplikasi ini merupakan program berbasis console yang digunakan untuk membantu menghitung ongkos kirim paket berdasarkan data paket yang dimasukkan oleh pengguna.

# Fitur Aplikasi
- Create: Menambahkan data paket.
- Read: Menampilkan data paket.
- Update: Mengubah data paket.
- Delete: Menghapus data paket.
- Search: Mencari data paket.
